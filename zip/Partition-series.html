About Partition Series

The Partition Series is Khidkie™’s complete aluminium framework for creating glass walls, cabins and integrated doors. Unlike simple frame systems, this series is designed as a full architectural partition platform with dedicated verticals, horizontals, door profiles and accessories for professional interior construction.

Where Partition Series Works Best

This system is used in corporate offices, conference rooms, hospitals, educational institutions, banks, retail showrooms and co-working spaces. It supports fixed glass walls, sliding doors and hinged doors within the same modular frame structure.

Why Fabricators Prefer Partition Series

Fabricators prefer this system because every part of a partition — wall, door and glass — has a dedicated aluminium profile. This allows fast layout, clean installation, accurate alignment and long-term structural reliability.

KHIDKIE™ PARTITION SYSTEM

A modular aluminium partition and door system built around SP, DP and door profile families for modern commercial and interior architecture.

The Partition Series is built around multiple structural families: SP (Single Partition) and DP (Double Partition) profiles for fixed glass walls, along with 47×44 and 85×44 door systems for integrated hinged and sliding doors. This allows a single system to create both open office layouts and enclosed cabins.

Wall stability and glass alignment are controlled using SP, DP, Leg and Corner Pipe profiles, which define vertical support, glass holding and frame geometry across the entire partition grid.

Door performance is handled using dedicated Door Vertical, Door Top, Door Middle, DMS and Door Bottom profiles, ensuring smooth operation, proper glass grip and long-term durability in high-traffic environments.

Unlike improvised office partitions, the Khidkie™ Partition Series is a true architectural partition system. Every profile is engineered to ensure:
• Straight glass lines
• Stable tall partitions
• Integrated door frames
• Clean visual symmetry
• Long-term alignment

This makes the Partition Series ideal for both commercial projects and premium interior developments where appearance, durability and modular flexibility are equally important.
